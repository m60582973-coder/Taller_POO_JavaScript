# Taller de Programación Orientada a Objetos en JavaScript

## Descripción
Este proyecto contiene 10 ejercicios prácticos de programación orientada a objetos (POO) en JavaScript, basados en situaciones de la vida cotidiana. Su objetivo es aplicar conceptos fundamentales mediante la creación de clases, objetos, métodos y validaciones.

## Objetivo
Desarrollar habilidades de programación utilizando encapsulamiento, herencia, polimorfismo, arreglos, manejo de errores y pruebas de funcionamiento.

## Ejercicios realizados
1. **Sistema de cuentas bancarias:** administración de cuentas, saldos y retiros.
2. **Tienda y carrito de compras:** cálculo de precios y control de productos.
3. **Sistema de transporte:** administración de vehículos y cálculo de costos de viajes.
4. **Agenda de citas médicas:** registro y validación de citas.
5. **Gestión de empleados y nómina:** administración de empleados.
6. **Biblioteca y préstamos:** registro, préstamo y devolución de recursos.
7. **Pedidos de un restaurante:** administración de productos y cálculo de pedidos.
8. **Servicios de reparación del hogar:** registro de servicios y cálculo de costos.
9. **Sistema de reservas turísticas:** administración de reservas.
10. **Adopción y cuidado de mascotas:** registro de adopciones y control de cuidados.

## Conceptos aplicados
- **Clases y objetos:** representación de elementos de cada sistema.
- **Encapsulamiento:** protección de datos mediante atributos privados.
- **Herencia:** reutilización de características y métodos de una clase padre en clases hijas.
- **Polimorfismo:** implementación de métodos con comportamientos diferentes en las clases derivadas.
- **Arreglos:** almacenamiento y administración de varios objetos.
- **Validación de datos:** comprobación de información antes de ejecutar operaciones.
- **Manejo de errores:** uso de `throw`, `try` y `catch` para controlar situaciones inválidas.

## Requisitos previos
Para ejecutar los ejercicios se necesita tener instalado Node.js.

## Cómo ejecutar los ejercicios

1. Descargar o clonar el repositorio.
2. Abrir la carpeta `Taller_POO_JavaScript` en Visual Studio Code.
3. Abrir la terminal desde Visual Studio Code.
4. Ejecutar el comando correspondiente al ejercicio que se desea probar.
